# Linear-Regression-for-Bioprocess-Prediction-in-Python

This project is a simple machine learning exercise in Python focused on linear regression in a biotechnology context. The objective is to explore if biomass concentration can be used to predict product concentration.

## Project goal

The aim of this project is to practice the basic workflow of a linear regression model. The project includes:

- Loading and exploring a dataset
- Visualizing the relationship between biomass and product concentration
- Splitting the data into train and test sets
- Training a linear regression model
- Making predictions
- Evaluating model performance with R²
- Plotting the regression line

## Tools used

- Python
- pandas
- matplotlib
- scikit-learn
- Jupyter Notebook

## Dataset

The dataset used in this project has been manually created for educational purposes. It contains two variables:

- Biomass (g/L)
- Product (g/L)

## Main idea

In this project:

- `biomass_gL` is the input variable (`X`)
- `product_gL` is the target variable (`y`)

The model is trained to predict product concentration from biomass concentration using simple linear regression.
